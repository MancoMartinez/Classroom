What is the action for each status response? How is communication with the customer on each of them?

Letter templates URL.

PROCESS SUMMARY (from the article — for reference)
Submitting a dispute
- In Jira, open the ticket created by the consumer's dispute; read it to confirm it is a valid dispute letter (not a RAR request).
- Retrieve the transaction ID (TID#) from the letter, enter it in CRM, and check whether a dispute is already open for that consumer — if so, do not submit a duplicate.
- Enter the dispute in CRM: Admin → Consumer Disputes → Add Dispute → TID#, Nature of issue = "Complaint", Notes = "Consumer sent dispute letter for [retailer], waiting for response", date received, Jira ticket #, Submit.
Handling the retailer's response
- Retrieve response: CRM → Admin → Consumer Disputes → All Retailers → select retailer → Retailer's Response → Download.
- Act on the decision (Void / Place on Approval — see Q4).
- Prepare & upload the response letter (templates + save path in Q5), then CRM Admin → Consumer Disputes → Edit → enter Reply Date, upload letter, Submit.
- Finalize: in Jira, Reply to Customer, mark DONE; in CRM click Close with Action = No Action, Subject = Retailer Request, Resolution Action = retailer's decision → Close Dispute.
